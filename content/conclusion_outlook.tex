\chapter{Conclusion and Outlook}\label{chap:zusfas}
We have created a new way of active learning for an already known benchmark AL4PDE and 
thereby replaces the old Pool-Based approach. 
AL4PDE is an benchmark created by Musekamp et al., combining an ensemble for solving PDEs with 
active learning. To generate training data, a numerical solver is used and the variance between
the models inside the ensemble for a sample is modeled as a probabalistic function and called
"uncertainty". In this work, we sampled directly from the input space using 
a variation of MCMC. We start with $n$ parallel initial states, consisting of both ICs and 
PDE parameter, and create $n$ new states. This allows the usage of the gradient of the uncertainty
of the model to sample from the global uncertainty instead of 
being locally restricted like the Pool-Based approach. 
We therefore chose as tranistion probability from one state to the next a discretised version
of the langevin diffusion:
\[
N(U_{n-1}\frac{h}{2} \nabla \pi(U_{n-1}), hI_d)
\] 
where $\nabla\log\pi(U_{n-1})$ denotes the gradient of the logarithm of the previous state $U_{n-1}$.
Since we are mainly intrested in querying higher uncertainties we only use the last state 
of the markov chain as input for our numerical solver.
